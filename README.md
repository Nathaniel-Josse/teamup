# 🏃‍♂️ TeamUp! 🏃‍♀️

## Installation

For dev:<br>
`cd ./teamup-back` => `npm run dev`<br>
`cd ./teamup-back` => `npm run chat`<br>
`cd ./teamup-front` => `npm run dev`

## Description

TeamUp is a web application designed to manage and organize team sports activities. It allows users to create events and join team chats, and communicate with team members.
